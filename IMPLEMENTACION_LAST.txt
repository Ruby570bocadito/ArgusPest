1.2  REFACTOR api/grpc_server.py — BEACON STREAM REAL
───────────────────────────────────────────────────────
Archivo: api/grpc_server.py (290 lineas)

Problema actual:

Nueva arquitectura — Command Pipeline:

  Director                                  gRPC Beacon Stream
  ┌──────────────────────┐                  ┌──────────────────────┐
  │ ExploitManager        │                  │ AgentC2Servicer      │
  │ _dispatch_to_agent()──┼──► put(cmd) ──► │ _pending_commands    │
  │                      │                  │   [agent_id]         │
  │ ReconManager          │                  │   ┌───────────────┐ │
  │ _dispatch_scan()──────┼──► put(cmd) ──► │   │ asyncio.Queue │ │
  └──────────────────────┘                  │   └───────┬───────┘ │
                                            │           │ get()   │
                                            │           ▼         │
                                            │  Beacon() stream    │
                                            │  ─────────────────► │──► Agente Go
                                            │  ◄───────────────── │◄── Heartbeat
                                            └──────────────────────┘

Implementacion:

  1. Agregar a Director:
     self._pending_commands: Dict[str, asyncio.Queue] = {}

  2. Metodo Director.queue_command(agent_id, command):
     if agent_id not in self._pending_commands:
         self._pending_commands[agent_id] = asyncio.Queue(maxsize=10)
     await self._pending_commands[agent_id].put(command)

  3. Refactor ExploitManager._dispatch_to_agent():
     cmd = DirectorCommand(type=EXPLOIT, exploit_cmd=ExploitCommand(
         target_host=host_id, technique=action, cve=cve, params=params))
     await self.director.queue_command(agent_id, cmd)

  4. Refactor ReconManager._dispatch_scan():
     cmd = DirectorCommand(type=SCAN, scan_cmd=ScanCommand(
         targets=[ip], scan_type="tcp_syn", ports=top_ports, rate=1000))
     await self.director.queue_command(agent_id, cmd)

  5. Refactor ArgosAgentC2Servicer.Beacon():
     async def Beacon(self, request_iterator, context):
         agent_id = None
         cmd_queue = self.director._pending_commands.get(agent_id)
         async for agent_event in request_iterator:
             agent_id = agent_event.agent_id
             # Procesar heartbeat
             if agent_event.HasField("hb"):
                 await self.director.process_heartbeat(...)
             # Procesar resultados de scan/exploit
             elif agent_event.HasField("scan"):
                 await self.director.process_finding(...)
             elif agent_event.HasField("exploit"):
                 await self.director.process_finding(...)
             # Intentar despachar comando pendiente
             try:
                 cmd = await asyncio.wait_for(cmd_queue.get(), timeout=0.5)
                 yield cmd  # Enviar comando al agente
             except asyncio.TimeoutError:
                 yield DirectorCommand(type=SLEEP)  # Keepalive

Profesionalismo extra:
  - Rate limiting: Queue(maxsize=10) evita memoria infinita
  - Command timeout: DirectorCommand.timeout_s se respeta. Si expira sin
    EXPLOIT_RESULT del agente, se marca como TIMED_OUT en el EventBus
  - Reconexion: si el stream se cae, comandos no enviados se reencolan
  - Logging estructurado: cada comando despachado/recibido se loguea con
    correlation_id unico

         stream, err := c.client.Beacon(context.Background())

         }

         go func() {
             ticker := time.NewTicker(time.Duration(c.interval) * time.Second)
             defer ticker.Stop()

─────────────────────────────
Archivo NUEVO: agents/cell/recon/ssh.go (~150 lineas)

Tecnica:
  1. TCP connect al puerto 22, leer banner inicial (SSH-2.0-OpenSSH_7.4p1)

      IP         string

      Software   string   // "OpenSSH"
      Version    string   // "7.4p1"

      def __init__(self, host, port, director, tls_cert=None):
          self.director = director
          self.chameleon = ChameleonC2()
          self._clients = {}

      async def _handler(self, websocket, path=""):
          agent_id = None
          async for message in websocket:
              # 1. Desenvolver payload protobuf del JSON camuflado
              raw = self.chameleon.unwrap(message)
              if not raw:

  type JitterConfig struct {
      BaseInterval time.Duration  // beacon base: 60s, 120s, 15s
      JitterRange  float64        // +/- 20%, 40% del base
      SleepAfterCmd time.Duration // despues de recibir comando, dormir mas
  }

  func (c *Cell) jitteredSleep() {
      jitter := time.Duration(
          float64(c.cfg.BaseInterval) *
          (1.0 + (rand.Float64()-0.5)*c.cfg.JitterRange))
      time.Sleep(jitter)
  }

  func (c *Cell) beacondWithJitter() {
      for {
          select {
          case <-c.ctx.Done():
              return
          case cmd := <-c.commandChan:
              // Recibio comando, responder inmediatamente
              c.executeCommand(cmd)
              // Despues de comando, beacon mas lento (evitar correlacion)
              time.Sleep(c.cfg.SleepAfterCmd)
          case <-time.After(c.jitteredInterval()):
              // Heartbeat normal
              c.sendHeartbeat()
          }
      }
  }

      for _, proto := range cm.order {
          err := cm.tryConnect(ctx, proto)
          if err == nil {

              log.Printf("[Comms] Conectado via %s", cm.active)

      }
      return fmt.Errorf("todos los protocolos fallaron")
  }

      return cm.clients[cm.active].send(event)

  class MissionReplay:
      def __init__(self, event_log_path):
          self.events = [json.loads(l) for l in open(event_log_path)]

      async def replay(self, speed: float = 1.0):
          """Reproduce una mision desde el event log.

          bus = EventBus()  # Bus aislado para replay
          kt = KnowledgeTree()
          for event in self.events:

              # Reconstruir KnowledgeTree incrementalmente
              await self._apply_to_kt(kt, event)
              await asyncio.sleep(event["delay"] / speed)
          return kt, bus.get_history()

R E S U M E N   P O R   F A S E S
================================================================================

FASE 1 (gRPC)          ~15h    Desbloquea toda la comunicacion real
  - Stubs proto generados
  - Command pipeline (Director -> cola -> Beacon stream -> agente)
  - Go agent gRPC real
  - Comando 'connect' en consola

FASE 2 (Recon)         ~30h    El agente detecta TODO con detalle profesional
  - HTTP/SSH/MySQL/MSSQL/PG/FTP/RDP/Redis/SNMP fingerprint
  - OS detection multi-fuente
  - Web path bruteforce
  - Integracion de modulos en scanner.go

FASE 3 (Exploit)       ~25h    Ataques reales contra los targets del lab
  - Decision Engine -> MSF RPC con mapping de acciones a modulos
  - Brute force module (SSH, FTP, RDP, SMB)
  - Default credential checker
  - Exploit chaining (multi-step)
  - Comando 'exploit' / 'chain' en consola

FASE 4 (Post-Exploit)  ~20h    El agente extrae valor real del target
  - Credential dump REAL (LSASS direct syscalls, SAM parsing)
  - Persistencia avanzada (WMI, COM hijacking, PAM, LD_PRELOAD)
  - Lateral movement (PsExec, WMI, WinRM, SSH pivot)
  - Privilege escalation (sudo/GTOBins, SUID, UAC bypass)
  - Exfiltration (HTTP, DNS, ICMP)

FASE 5 (C2)            ~15h    Comunicacion profesional y resiliente
  - Chameleon C2 integrado con Director real
  - TLS en gRPC + WebSocket
  - Multi-protocol fallback (gRPC -> WS -> DNS -> ICMP)
  - Beacon jitter real con configuracion por perfil
  - C2 infrastructure con domain fronting

FASE 6 (UX)            ~20h    Herramienta profesional para operadores
  - Dashboard web (React + Cytoscape.js + gRPC-Web streaming)
  - TUI dashboard migrado a gRPC stream
  - Report generation (HTML/PDF con ATT&CK mapping)
  - Mission replay
  - Consola interactiva completa (10+ comandos nuevos)

Orden recomendado (cada fase desbloquea la siguiente):

  Semana 1:  Fase 1 (gRPC)
  Semana 2:  Fase 2 (Recon) + inicio Fase 3 (Exploit)
  Semana 3:  Fase 3 (Exploit) + Fase 4 (Post-Exploit)
  Semana 4:  Fase 4 (Post-Exploit) + Fase 5 (C2)
  Semana 5:  Fase 5 (C2) + Fase 6 (UX)
  Semana 6:  Fase 6 (UX) + testing final + documentacion

MVP utilizable despues de Fase 3 (3 semanas):
  - Agente Go escanea lab real, reporta via gRPC al Director
  - Decision Engine evalua servicios reales
  - MSF ejecuta exploits reales
  - Operador controla todo desde la consola interactiva
